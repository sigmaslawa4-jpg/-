# City Grid (Fabric 1.21.1)

Фонарные и электрические столбы, которые ломаются от молний и случайных неполадок.

## Сборка (нужна Java 21)
    ./gradlew build        (Windows: gradlew.bat build)
Готовый мод: build/libs/citygrid-1.0.0.jar -> в папку mods (Fabric Loader 0.16+ и Fabric API).
Тест в игре: ./gradlew runClient

## Как работает
- Электрический столб: ставится в высоту, сверху траверса с изоляторами.
- Секция фонарного столба: металлическая труба для наращивания высоты.
- Уличный фонарь: горит ночью/в дождь, если в радиусе 8 блоков есть ИСПРАВНЫЙ электрический столб.
- Поломка: удар молнии (радиус 3 блока), гроза притягивает молнии к высоким столбам,
  плюс случайные неполадки (чаще в дождь и грозу). Сломанное искрит, фонарь гаснет.
- Ремонт: Набор электрика в руке + 1 медный слиток в инвентаре, ПКМ по сломанному блоку.
  Чинится сразу вся колонна столба.
- Настройки (шансы, радиусы, пожары от молнии): GridConfig.java

## Рецепты
- Электрический столб x2: медный слиток сверху, под ним 2 бревна (вертикально)
- Секция фонаря x4: 3 железных слитка в столбик
- Уличный фонарь: стекло крестом, в центре редстоун-лампа, снизу железный слиток
- Набор электрика: 2 железа + медь + редстоун + палка (бесформенный)
