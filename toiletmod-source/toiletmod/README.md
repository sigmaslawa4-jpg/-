# Toilet & Internet Mod (Fabric 1.21.1) — этап 1+2

## Самый простой способ: сборка на GitHub
1. Загрузи все файлы проекта в репозиторий (включая папку `.github`).
2. Вкладка **Actions** -> запуск **Build mod** (или он стартует сам после push).
3. Дождись зелёной галочки, открой запуск, внизу в **Artifacts** скачай `toiletmod-jar`.
4. Распакуй, внутри будет `toiletmod-0.1.0.jar`. Это и есть мод.
   Красный крестик = ошибка: открой шаг Build и пришли мне текст ошибки.

Мод работает только на **Fabric** (не Forge/NeoForge), Minecraft 1.21.1, и нужен Fabric API.

## Как собрать jar у себя
Нужна **Java 21** (проверка: `java -version`) и интернет.

Windows:  `gradlew.bat build`
Linux/Mac: `./gradlew build`

Готовый мод: `build/libs/toiletmod-0.1.0.jar`  (НЕ берите файл с `-sources`)
Положить в папку `.minecraft/mods` вместе с **Fabric API 0.105.0+1.21.1** и Fabric Loader 0.16+.

Если что-то не собралось — пришлите текст ошибки целиком.

## Что есть
- Две полоски в левом верхнем углу: «Пописать» (полная за 10 мин) и «Покакать» (за 20 мин).
  При 100% — «авария»: замедление (и тошнота для второго).
- Унитаз: ПКМ — сбрасывает полоски.
- Роутер (радиус 32) и интернет-станция (радиус 96).
- Телевизор: ПКМ включает, только если рядом есть роутер/станция. Пропал интернет — телек гаснет.
- Всё во вкладке креатива «Туалет и интернет», есть крафты.
- Команда для теста (нужны права оператора): `/needs 100 100`
  (первое число — пописать, второе — покакать).
