# Toilet & Internet Mod (Fabric 1.21.1) — этапы 1-3

## Самый простой способ: сборка на GitHub
1. Загрузи все файлы проекта в репозиторий (включая папку `.github`).
2. Вкладка **Actions** -> запуск **Build mod** (или он стартует сам после push).
3. Дождись зелёной галочки, открой запуск, внизу в **Artifacts** скачай `toiletmod-jar`.
4. Распакуй, внутри будет `toiletmod-0.2.0.jar`. Это и есть мод.
   Красный крестик = ошибка: открой шаг Build и пришли мне текст ошибки.

Мод работает только на **Fabric** (не Forge/NeoForge), Minecraft 1.21.1, и нужен Fabric API.

## Как собрать jar у себя
Нужна **Java 21** (проверка: `java -version`) и интернет.

Windows:  `gradlew.bat build`
Linux/Mac: `./gradlew build`

Готовый мод: `build/libs/toiletmod-0.2.0.jar`  (НЕ берите файл с `-sources`)
Положить в папку `.minecraft/mods` вместе с **Fabric API 0.105.0+1.21.1** и Fabric Loader 0.16+.

Если что-то не собралось — пришлите текст ошибки целиком.

## ВАЖНО для этапа 3: нужен мод MCEF
Телевизор и компьютер показывают сайты через Chromium, его даёт мод **MCEF**.
1. Скачай **MCEF для Fabric 1.21.1** (версия 2.1.x) с Modrinth или CurseForge и положи в `mods`.
2. При первом запуске MCEF сам скачает Chromium (~200 МБ). Нужен интернет, подожди окончания.
3. Антивирус может блокировать MCEF: добавь папку игры в исключения.
Если MCEF нет, мод всё равно работает, но вместо браузера будет сообщение.

## Для телевизора и компьютера (браузер) нужен ещё мод MCEF
Скачай **MCEF для Fabric 1.21.1** (версия 2.1.6-1.21.1) на Modrinth или CurseForge и положи в `mods`.
При первом запуске он сам скачает Chromium (~200 МБ, нужен интернет) — подожди, пока загрузится.
Без MCEF остальной мод работает, а при открытии браузера покажет подсказку.

## Что есть
- Две полоски в левом верхнем углу: «Пописать» (полная за 10 мин) и «Покакать» (за 20 мин).
  При 100% — «авария»: замедление (и тошнота для второго).
- Унитаз: ПКМ — сбрасывает полоски.
- Роутер (радиус 32) и интернет-станция (радиус 96).
- Телевизор: ПКМ включает (нужен роутер/станция рядом). Потом ПКМ — открывается экран:
  вставь ссылку на YouTube-видео в строку сверху и нажми Enter. Shift+ПКМ — выключить.
  Пропал интернет — телевизор гаснет. Esc закрывает экран.
- Компьютер: ПКМ открывает браузер (Google). Любой сайт, поиск, онлайн-игры; ИИ-сайты тоже (например, gemini.google.com).
- Всё во вкладке креатива «Туалет и интернет», есть крафты.
- Команда для теста (нужны права оператора): `/needs 100 100`
  (первое число — пописать, второе — покакать).
